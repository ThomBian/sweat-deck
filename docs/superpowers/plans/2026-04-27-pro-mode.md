# Pro Mode (Manual Deck Setup) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Manual mode so coaches can assign exercises directly to every card slot without going through the setup wizard, accessible from the landing page via a Guided / Manual toggle.

**Architecture:** The existing `/review` route is renamed to `/deck` and refactored around a `useDeckComposer` hook that owns all slot state for both Guided (config-driven, pre-filled) and Manual (blank slots, coach assigns each) modes. The landing page gains a segmented toggle + contextual descriptor + a single "Go!" CTA that routes to either the wizard (Guided) or directly to the deck builder (Manual). `DeckBuilder` becomes a thin shell over the hook; no mode-specific conditionals leak into slot-card components.

**Tech Stack:** React 19, TypeScript 6, Zustand, React Router v6, Framer Motion, Lingui, Tailwind v4, Vitest + Testing Library, Playwright

```ts
import { useEffect, useState } from 'react';
import { useNavigate } from 'react-router-dom';
import { useGameStore } from '@/store/gameStore';
import { buildPlan, buildManualSlots, type SlotKey, type PlanSlot } from '@/domain/plan';
import { DEFAULT_CONFIG, type SetupConfig } from '@/domain/config';
import type { ExerciseId } from '@/domain/exercise';
import { saveLastConfig } from '@/store/db';

export type ComposerMode =
  | { mode: 'guided'; config: SetupConfig }
  | { mode: 'manual' };

export type ComposerSlot = {
  key: SlotKey;
  selected: ExerciseId | undefined;
  options: PlanSlot['options'];
  defaultExercise: PlanSlot['defaultExercise'] | undefined;
};

export type DeckComposerState = {
  slots: ComposerSlot[];
  isReady: boolean;
  setSlot: (key: SlotKey, id: ExerciseId) => void;
  handleStart: () => Promise<void>;
  footerLocked: boolean;
  showShuffle: boolean;
  hasOverrides: boolean;
  resetOverrides: () => void;
};

export function useDeckComposer(input: ComposerMode): DeckComposerState {
  const navigate = useNavigate();
  const overrides = useGameStore((s) => s.overrides);
  const setOverride = useGameStore((s) => s.setOverride);
  const storeResetOverrides = useGameStore((s) => s.resetOverrides);
  const start = useGameStore((s) => s.start);
  const [showShuffle, setShowShuffle] = useState(false);
  const [isStarting, setIsStarting] = useState(false);

  useEffect(() => {
    storeResetOverrides();
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);

  const config = input.mode === 'guided' ? input.config : DEFAULT_CONFIG;

  const slots: ComposerSlot[] =
    input.mode === 'guided'
      ? (buildPlan({ config, overrides }) as ComposerSlot[])
      : buildManualSlots().map((key) => ({
          key,
          selected: overrides[key] as ExerciseId | undefined,
          options: [] as PlanSlot['options'],
          defaultExercise: undefined,
        }));

  const isReady =
    input.mode === 'guided' ? true : slots.every((s) => s.selected !== undefined);

  const hasOverrides = input.mode === 'guided' && Object.keys(overrides).length > 0;

  const setSlot = (key: SlotKey, id: ExerciseId) => {
    setOverride(key, id);
  };

  const handleStart = async () => {
    if (showShuffle || isStarting) return;
    setIsStarting(true);
    if (input.mode === 'guided') {
      try {
        await saveLastConfig(config);
      } catch {
        // non-blocking
      }
    }
    start(config);
    setShowShuffle(true);
  };

  return {
    slots,
    isReady,
    setSlot,
    handleStart,
    footerLocked: showShuffle || isStarting,
    showShuffle,
    hasOverrides,
    resetOverrides: storeResetOverrides,
  };
```

### Notes for implementer

- `gameStore.start(DEFAULT_CONFIG)` is called in manual mode. It internally calls `saveLastConfig(DEFAULT_CONFIG)` — this is an accepted limitation for this iteration. The next guided workout session will overwrite it.
- `DeckSlotCard` receives `DEFAULT_CONFIG` as the `config` prop in manual mode (used by `ExercisePickerSheet` for face card prescription previews). Prescriptions show bodyweight/intermediate defaults, which is fine since the coach overrides everything.
- The `useDeckComposer` hook is split into an outer `DeckBuilder` (redirect guard) and inner `DeckBuilderInner` (hook consumer) to satisfy React's rules of hooks — hooks cannot be called conditionally, and the outer component needs to return null before hooks run if `mode === 'guided'` but `config` is missing.
